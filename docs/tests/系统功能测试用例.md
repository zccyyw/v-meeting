### TC-AUTH-005 边界值-连续5次失败后账户锁定

| 项目 | 内容 |
|------|------|

### TC-AUTH-013 场景-密码 AES-GCM 加密传输

|------|------|
| **测试模块** | 登录认证 |
| **测试标题** | 前端密码经 AES-GCM-256 加密后传输，后端正确解密 |
| **前置条件** | 系统已启动，test1 用户存在 |
| **测试步骤** | 1. 前端调用 `encryptPassword('123456')` 加密密码<br>2. 将加密后的 `enc:<base64 iv>:<base64 ciphertext>` 字符串作为 password 提交登录<br>3. 后端 `decryptPassword()` 解密后验证 |
| **预期结果** | 1. 前端生成 `enc:` 前缀格式的密文字符串<br>2. 后端正确解密得到明文 `123456`<br>3. 登录验证通过，返回成功 |
