## 一、账号与认证

### 1.1 登录

- 账号密码登录，密码经 `bcryptjs`（cost 10）哈希存储
- 登录成功返回 `sessionId`（`nanoid(32)`），存入 Redis，TTL 7 天
- 客户端通过 `x-session-id` 请求头携带会话
- 账号停用（`status != 0`）拒绝登录
- **登录失败锁定**：连续失败达阈值（默认 5 次）后锁定账户，锁定时长可配置（默认 60 秒）
- **登录日志**：每次登录成功/失败自动记录到 `sys_oper_log`（含 IP、用户名、失败原因）
- **默认密码检测**：登录时检测是否为默认密码，返回 `mustChangePassword` 标志
- **密码过期检测**：登录时检测密码是否过期（默认 90 天），返回 `passwordExpired` 标志

### 1.2 会话校验

- 每次 API 请求经 `loadSessionUser` 从 Redis 取 `userId`，再查 `sys_user` 表（或旧 `users` 表向后兼容）
- 加载用户角色（`sys_role`）和权限（`sys_menu` 按钮权限）
- 会话过期或失效返回 401，前端自动跳转登录页
- **系统管理后台独立入口**：`/manager/login`，与会议应用互不干扰

### 1.3 密码管理

| 操作 | 说明 | 权限 |
|------|------|------|
| 修改密码 | 校验旧密码 → 策略校验新密码 → 更新密码，同时更新 `pwd_update_date` | 本人 |
| 重置密码 | 管理员提交审批 → 授权管理员审批通过后执行 | 系统管理员 → 授权管理员 |

### 1.4 角色体系（三员分立）

| 层级 | 角色 | role_key | 说明 |
|------|------|---------|------|
| **超级管理员** | `admin` | `admin` | 全部权限，管理三员、系统设置 |
| **系统管理员** | `sys_admin` | `sys_admin` | 用户管理（查询/新增/编辑）、部门管理、参数设置 |
| **授权管理员** | `auth_admin` | `auth_admin` | 用户操作审批、登录日志查询 |
| **审计管理员** | `audit_admin` | `audit_admin` | 全量操作日志查询/导出/删除 |
| **普通用户** | `common` | `common` | 仅会议功能，无系统管理入口 |
| **会议角色** | `host` / `participant` / `guest` | — | 主持人 / 参会者 / 访客（运行时动态分配） |

> 📌 三员分立遵循安全合规要求：系统管理员可操作用户但不能审批；授权管理员可审批但不能直接操作用户；审计管理员仅查看日志。超级管理员 `admin` 兼具所有权限。

## 二、会议管理

### 2.1 快速会议

- 一键创建即时会议，生成 9 位会议码
- 创建者自动获得 `host` 令牌（24h 有效）
- 默认入会关闭摄像头

### 2.2 预约会议

- 设置主题、预约时间、可选入会密码
- 入会密码经 `bcrypt` 哈希存 `meetings.join_password_hash`
- 主持人免密码校验

### 2.3 加入会议

| 方式 | 流程 | 令牌有效期 |
|------|------|-----------|
| 会议号加入 | 输入会议号 → 校验入会密码 → 获取令牌 | 6h |
| 历史记录加入 | 从历史列表一键加入 → 获取令牌 | 6h |
| 访客加入 | 无需登录 → `POST /meetings/:id/guest-token` | guest 令牌 |

> 📌 信令服务通过 `auth-bridge.ts` 直接查库校验令牌，不依赖 Redis。

### 2.4 等候室与批准入会

- 主持人可在会议中动态开关等候室（设置面板勾选「开启批准入会」）
- **开启时**：非 host 角色入会先进等候室，主持人批准后进入
- **关闭时**：直接进入会议

### 2.5 会议邀请名单

- 创建会议时可选择邀请用户和部门
- 邀请名单存 `meeting_invitations` 表，状态：`pending` → `attended`
- 信令服务 `join` / `leave` 时自动更新邀请状态
- 前端可查看邀请名单及在线/离线状态

### 2.6 会议结束

- 主持人可结束会议（`Power` 图标），状态置为 `ended`
- 房间空置 5 秒后自动销毁，释放 mediasoup 资源
- 已结束会议不可再加入

## 三、音视频

### 3.1 设备控制

| 功能 | 说明 |
|------|------|
| 麦克风开关 | 一键开关麦克风 |
| 摄像头开关 | 一键开关摄像头 |
| 设备切换 | 下拉选择麦克风/摄像头 |
| 默认状态 | 入会默认关闭摄像头（快速/加入/预约会议均一致） |

### 3.2 说话指示

- 基于 Web Audio API 的 `AnalyserNode` 实时采集音频，计算 RMS
- 超过阈值（0.06）判定为说话，经去抖动（开 120ms / 关 600ms）后提交状态
- 说话时在视频宫格左下角或头像左下角显示**绿色声波条动画**（3 根动态柱）
- 本地与远端用户均显示说话指示

### 3.3 静音状态同步

- `PeerInfo` 携带 `micEnabled` / `camEnabled` 状态
- 信令协议 `newProducer` / `producerPaused` / `producerClosed` 消息携带 `source`（`microphone` / `camera` / `screen`）与 `paused` 字段
- 用户静音时，其他用户在其视频宫格/头像左下角看到**灰色 `MicOff` 图标**

### 3.4 摄像头与布局联动

| 摄像头状态 | 布局表现 |
|-----------|---------|
| 开启 | 宫格布局显示视频画面 |
| 关闭 | 切换为头像模式（圆形头像 + 名称） |
| 远端状态变更 | 实时同步并自动切换布局 |

### 5.1 共享方式

- 调用 `getDisplayMedia`，用户可选择共享：

| 共享源 | 说明 |
|--------|------|
| 整屏（monitor） | 共享整个显示器画面 |
| 应用窗口（window） | 共享单个应用窗口 |
| 浏览器标签页（browser） | 共享单个浏览器标签 |

- 监听 `displaySurface` 字段

- 避免共享内容包含会议界面自身导致的无限嵌套

### 5.3 主持人管控

- 主持人可允许 / 禁止成员共享屏幕

## 八、系统管理（若依风格 RBAC）

> 📌 系统管理后台独立入口 `/manager/`，与会议应用分离。基于若依风格的 Top+Left+Content 布局，使用 Ant Design 组件。

### 8.1 用户管理（`/manager/user`）

- 用户 CRUD：用户名、昵称、手机号、部门、角色、状态
- 用户查询：支持按用户名/手机号模糊搜索、按状态/部门/创建时间筛选
- 启用 / 停用账号
- 重置密码
- 导入 / 导出 Excel（`.xlsx` / `.csv`）
- **审批流程**：系统管理员提交用户操作（新增/编辑/删除/重置密码）→ 授权管理员审批 → 执行

### 8.2 部门管理（`/manager/dept`）

- 树形部门结构（父子关系）
- 部门 CRUD、查询
- 部门下用户列表

### 8.3 角色管理（`/manager/role`）

- 角色 CRUD：角色名称、权限字符、排序、数据范围
- 菜单权限分配：树形勾选菜单（目录/菜单/按钮）
- 数据范围：全部 / 自定义 / 本部门 / 本部门及以下

### 8.4 菜单管理（`/manager/menu`）

- 树形菜单结构：目录（M）/ 菜单（C）/ 按钮（F）
- 菜单 CRUD：名称、路径、组件、图标、权限标识、排序
- 按钮权限标识（如 `system:user:add`）

### 8.5 参数设置（`/manager/config`）

- 系统配置项管理（`sys_config` 表）
- 密码策略配置：最小/最大长度、大小写/数字/特殊字符要求、过期天数、禁止复用
- 登录安全配置：最大失败次数、锁定时长
- 会话配置：空闲超时秒数、超时前提醒秒数
- 日志配置：保留天数、存储空间阈值
- 在线用户配置：同时在线人数上限
- 配置缓存：60 秒 TTL，更新后自动失效

### 8.6 通知公告（`/manager/notice`）

- 公告 CRUD：标题、类型（通知/公告）、内容、状态
- 公告列表查询

### 8.7 操作日志（`/manager/operlog`）

- 自动记录用户操作（中间件 `oper-log.ts`）
- 登录日志：用户名、IP、状态（成功/失败）、失败原因
- 操作日志：操作人、模块、操作类型、请求参数、响应结果
- 日志查询：按时间范围、操作人、模块筛选
- 日志导出 / 删除
- **自动清理**：定时清理过期日志（默认 365 天）

### 8.8 用户审批（`/manager/user-approval`）

- 系统管理员提交的用户操作审批申请
- 授权管理员审批（通过/驳回）
- 支持的操作类型：新增用户、编辑用户、删除用户、重置密码
- 审批通过后自动执行操作

### 8.9 会议审批（`/manager/meeting-approval`）

- 普通用户提交会议申请
- 授权管理员审批（通过/驳回）
- 审批通过后自动创建会议
- 申请信息：标题、会议时间、结束时间、地点、参与部门数、优先级（高/中/低）、备注

## 九、群组管理与一键开会

### 9.1 群组管理（`/groups`）

- 创建群组：群组名称 + 从系统用户/部门中选择成员
- 成员选择器（`MemberPicker` 组件）：左侧用户/部门树，右侧已选成员
- 群组列表：群组名称、成员数（含部门展开后的人数）、创建时间
- 编辑群组：修改名称、追加/移除用户、追加/移除部门
- 删除群组

### 9.2 一键群组开会

- 选择群组 → 一键发起会议
- 自动创建会议 + 邀请全部群组成员
- 可设置会议标题、等候室开关
- 群组成员展开：部门自动展开为部门下所有用户

### 9.3 数据结构

- `meeting_groups`：群组基本信息（名称、创建者）
- `meeting_group_members`：群组成员（用户或部门）
- 部门展开：查询时自动将部门展开为部门下所有活跃用户

## 十、会议申请审批

### 10.1 会议申请

普通用户可提交会议申请，包含以下信息：

| 字段 | 说明 |
|------|------|
| 标题 | 会议主题（必填） |
| 会议时间 | 预约开始时间（必填） |
| 结束时间 | 预计结束时间 |
| 地点 | 会议地点 |
| 参与部门数 | 参与部门数量 |
| 优先级 | 高 / 中 / 低（默认中） |
| 备注 | 补充说明 |

### 10.2 审批流程

1. 普通用户提交申请 → 状态 `pending`
2. 授权管理员审批 → 通过则状态 `approved`，驳回则状态 `rejected`
3. 审批通过后自动创建会议，关联 `meeting_id`
4. 驳回时填写驳回原因

### 10.3 数据结构

- `meeting_applications` 表：申请信息 + 审批状态 + 会议关联

## 十一、会议录制

### 11.1 录制机制

- **客户端录制**：浏览器侧用 Canvas 合成视频 + 混合音频，通过 `MediaRecorder` 编码为 WebM
- 录制参数：1280×720、15fps、1.5Mbps
- 单文件上限 1GB

### 11.2 录制元数据

录制元数据存 `recordings` 表：

| 字段 | 说明 |
|------|------|
| `meeting_id` | 所属会议 |
| `owner_user_id` | 录制者 |
| `title` | 录制标题 |
| `duration_ms` | 时长（毫秒） |
| `size_bytes` | 文件大小 |
| `storage_path` | 存储路径 |
| `source` | 来源 |

### 11.3 录制历史

- 侧边栏「录制」入口查看本人所有录制
- 支持下载与删除
- 仅能查看本人创建的录制

## 十三、安全与合规模块

### 13.1 三员分立

| 角色 | 职责 | 限制 |
|------|------|------|
| 系统管理员 | 用户管理、部门管理、参数设置 | 不能审批、不能查看全量日志 |
| 授权管理员 | 用户操作审批、登录日志查询 | 不能直接操作用户、不能查看全量日志 |
| 审计管理员 | 全量操作日志查询/导出/删除 | 不能操作用户、不能审批 |

### 13.2 密码策略

所有参数通过 `sys_config` 表配置，无硬编码：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `sys.password.minLength` | 8 | 最小长度 |
| `sys.password.maxLength` | 128 | 最大长度 |
| `sys.password.requireUpper` | true | 需要大写字母 |
| `sys.password.requireLower` | true | 需要小写字母 |
| `sys.password.requireDigit` | true | 需要数字 |
| `sys.password.requireSpecial` | true | 需要特殊字符 |
| `sys.password.specialChars` | `!@#$%^&*()_+-=[]{}|;:,.<>?/` | 特殊字符集 |
| `sys.password.expireDays` | 90 | 过期天数（0=不过期） |
| `sys.password.preventReuse` | true | 禁止与旧密码相同 |
| `sys.password.defaultPasswords` | `123456,admin123,Admin@123` | 默认密码列表 |

### 13.3 登录安全

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `sys.login.maxAttempts` | 5 | 连续登录失败最大次数 |
| `sys.login.lockDuration` | 60 | 账户锁定时长（秒） |

- 失败计数窗口：5 分钟
- 达到阈值后锁定账户，期间拒绝登录（HTTP 423）
- 登录成功后清除失败计数

### 13.4 操作日志

- 中间件 `oper-log.ts` 自动记录写操作（POST/PUT/DELETE）
- 登录日志：成功/失败、IP、用户名、失败原因
- 日志保留：默认 365 天，定时清理（每 24 小时执行一次）
- 存储阈值监控：默认 80%

### 13.5 HTTPS 与信创证书

| 部署方式 | 证书方案 | 脚本 |
|---------|---------|------|
| Docker Compose | 自签 / CA 签发 / 正式证书 | `deploy/docker/gen-selfsigned.sh [--ca]` |
| 离线包 | CA 签发（信创推荐） / 自有证书 | `/opt/meeting/bin/genssl.sh <IP>` |
| RPM 包 | 自签 / CA 签发（纯 JS） | `/opt/meeting/bin/gen-cert.mjs [--ca] <IP>` |

> 📌 信创环境（麒麟/UOS/中科方德）浏览器不允许直接信任自签名证书，必须使用 CA 签发模式：生成根 CA 证书 → 导入客户端信任库 → 由 CA 签发服务器 IP 证书。

### 13.6 其他安全措施

| 安全措施 | 实现方式 |
|---------|---------|
| 密码哈希 | `bcrypt`（cost 10） |
| 会话令牌 | `nanoid(32)` 随机生成 |
| 会议令牌 | `randomBytes(32).toString("hex")` |
| 入会密码 | `bcrypt` 哈希存储 |
| 信令层校验 | 直接查库校验令牌，不信任客户端声明 |
| API 鉴权 | `x-session-id` 请求头 |
| Zod 校验 | 全部 API 请求体经 Zod schema 校验 |

### 14.2 迁移机制

| 项 | 说明 |
|----|------|
| 脚本目录 | `serve/api/src/sql/{mysql,postgres,sqlite}/` 按方言分目录 |
| 执行顺序 | `001_init.sql` → `002_users_admin.sql` → `003_meeting_join_password.sql` → `004_recordings.sql` → `005_meeting_record_permission.sql` → `006_sys_manager.sql` → `007_meeting_invitations.sql` → `008_sys_security.sql` → `009_meeting_applications.sql` → `010_meeting_invitations_unique.sql` |
| 自动迁移 | API 启动时自动执行（`migrate.ts`），幂等可重复 |
| 兼容性 | 002/003 通过检测后 ALTER 补列；008 安全模块检测列是否存在再添加 |
| PostgreSQL | 额外创建 `meeting_set_updated_at()` 触发器 |
