## 条目解读与规范化

**架构类型**（按包管理/工具链命名规范对齐）

| 表格写法 | 标准架构名 | 典型 CPU |
|---|---|---|
| x86 | `x86_64`（amd64） | 海光、兆芯 |
| arm | `aarch64`（arm64） | 鲲鹏、飞腾 |
| loongarch | `loongarch64` | 龙芯 3A5000 / 3C5000 |

**覆盖范围**

- 服务器：银河麒麟、中科方德，三种架构（loongarch64 / aarch64 / x86_64），**离线安装**，系统无 JAVA，支持 Nginx。版本栏为空，按主流版本覆盖（银河麒麟 V10 SP1~SP3、中科方德高可信服务器系列）。
- 客户端：银河麒麟 / 统信桌面 V10 SP1、统信专业版 1050，三种架构，**离线安装**。
- 「是否支持 Nginx/JAVA 不确定」为客户端条目：本系统前端为浏览器访问的 Web/PWA 应用，**客户端不需安装 Nginx 或 JAVA**，仅要求自带浏览器满足 WebRTC 能力。

**关键约束**

1. 服务器与客户端均为**离线**环境，所有依赖（运行时、原生模块、构建工具）必须自包含。
2. **loongarch64（龙芯）为必选架构**，服务器与客户端均需覆盖。
3. 服务器不提供 JAVA 运行时——本系统为 Node.js 技术栈，不依赖 JAVA。
4. 服务器支持 Nginx，可用于静态托管与反向代理（仓库已有 `deploy/native/conf/nginx-meeting.conf`）。
